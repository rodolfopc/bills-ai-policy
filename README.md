# Política de Privacidade — Billzen

*Última atualização: 5 de maio de 2026*

---

## 1. Sobre o Billzen

O Billzen é um aplicativo de gestão de contas pessoais que funciona inteiramente no seu dispositivo. Nenhuma informação sua é enviada para servidores externos.

---

## 2. Dados coletados

**O Billzen não coleta, armazena ou compartilha nenhum dado pessoal.**

Todas as informações que você cadastra no aplicativo (contas, categorias, valores, datas) ficam salvas exclusivamente no armazenamento local do seu dispositivo. Não há conta de usuário, cadastro ou login.

---

## 3. Permissões utilizadas

O aplicativo solicita as seguintes permissões do sistema:

| Permissão | Finalidade |
|-----------|------------|
| **Notificações** | Enviar lembretes de vencimento de contas diretamente no dispositivo |
| **Inicialização com o sistema** | Reagendar os lembretes após reinicialização do dispositivo |

Nenhuma dessas permissões é usada para coletar ou transmitir dados.

---

## 4. Serviços de terceiros

O Billzen não utiliza serviços de terceiros que coletem dados, como analytics, publicidade ou rastreamento.

---

## 5. Acesso a dados bancários

O Billzen **não** solicita, acessa ou armazena dados bancários. Todas as informações são inseridas manualmente pelo usuário.

---

## 6. Crianças

O Billzen não coleta dados de nenhum usuário, independentemente da idade.

---

## 7. Alterações nesta política

Caso esta política seja alterada, a data de "última atualização" no topo será modificada. Como o aplicativo não coleta dados, alterações futuras serão apenas para maior clareza.
